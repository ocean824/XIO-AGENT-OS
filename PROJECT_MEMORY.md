# XIO Project Memory

## Durable decisions
- XIO is Ø's personal Founder Agent OS with future productization-ready multi-tenant foundations.
- FounderOS-DEMO is a reference/base inspiration; XIO substantially extends/rearchitects it.
- XIO natively includes CodeSpring-like specification compilation, Traycer-like Epic/ticket planning/orchestration, agent swarms, isolated execution, Smart-YOLO-style approved autonomous Epic execution, adversarial review, and XYRA Gauntlets. External versions of these tools are optional integrations.
- XIO FORGE is the software-development subsystem; XIO SWARM is the generalized multi-agent runtime; XIO BRAIN is governed knowledge/memory; XIO FLOW is workflow automation.
- Complete end-state architecture is planned before implementation; capability waves should not create disposable rewrites.
- Model/provider agnostic.
- First-class infrastructure profile: Neon + Cloudflare + R2 while preserving adapters.
- GitHub remains canonical durable source for software projects and XIO's own development.
- Consequential actions require policy/approval; autonomy is bounded and auditable.
- Large specification corpora use context manifests/selective retrieval.
