# XIO Unified Master Build Plan

XIO is one end-state architecture delivered through capability gates. Native FORGE/SWARM/BRAIN/FLOW foundations are not deferred into incompatible rewrites.

## Wave 0 — Engineering bootstrap
Monorepo, environments, CI/CD, schemas, tests, observability, secrets, feature flags, Git conventions, XYRA files/context registry.

## Wave 1 — Identity / tenancy / policy
Users, organizations/businesses/workspaces, memberships, RBAC/ABAC, policy engine, audit, approvals, budgets, secrets.

## Wave 2 — Core data/event platform
Postgres domain model, migrations, object store, queues/events, cache, jobs, notifications, connector SDK, API foundation.

## Wave 3 — BRAIN
Knowledge ingestion, hybrid retrieval, vector abstraction, source/signal/claim/fact/memory lifecycle, provenance, contradictions, scoped memory, procedural memory.

## Wave 4 — AI Gateway + SWARM
Provider/model registry, routing, structured output, agent profiles, tools, permissions, executions, budgets, evals, fallback, agent messaging/artifacts.

## Wave 5 — FORGE planning core
Software projects, repos, requirements, Epics, Specs, tech plans, waves, tickets, dependencies, ADRs, specification compiler, context manifests.

## Wave 6 — FORGE execution core
Git/worktrees, sandbox runner, tool broker, coding agents, parallel scheduler, execution logs, diffs, tests, artifacts.

## Wave 7 — FORGE adversarial / XYRA
Review council, findings, security/data/UX/performance reviewers, chaos/fault scenarios, Gauntlet engine, evidence ledger, promotions, deployments, rollback/recovery.

### Gate A — XIO can build XIO
Dogfood milestone: XIO FORGE must be capable of planning/executing/reviewing a bounded XIO feature under XYRA with evidence.

## Wave 8 — COMMAND / projects / tasks
Executive dashboard, movable widgets, universal chat/command, businesses, projects, goals, tasks, approvals, alerts, agent/build views.

## Wave 9 — COMMS / calendar / meetings
Email/messages/calendar connectors, unified inbox, drafts/actions, meeting intelligence, follow-up, memory.

## Wave 10 — DATA
Spreadsheet engine/workspace, imports/exports, SQL, transforms, charts, pipelines, schedules, lineage.

## Wave 11 — CRM / relationships / outreach
People/companies graph, deals, segmentation, campaigns, email/SMS, sequences, analytics, permissions.

## Wave 12 — GROWTH / funnels / web
Landing/funnel builder, forms, offers, domains, deploy/export, experiments, attribution, lead capture.

## Wave 13 — SOCIAL / CONTENT / ADS
Content system, asset library, publishing adapters, analytics, campaign/ad planning and authorized management.

## Wave 14 — STUDIO
Documents, proposals, reports, spreadsheets, animated HTML decks/presentations, creative provider adapters, brand systems.

## Wave 15 — MONEY
Finance dashboards, payments/invoices/subscriptions connectors, budgets, scenarios, reconciliation, alerts.

## Wave 16 — INTEL
News/research ingestion, watchlists, change detection, competitive/industry intelligence, briefs, action routing.

## Wave 17 — FLOW automation
Visual/code workflow builder, event triggers, schedules, approvals, retries, long-running state, skills/SOPs, workflow marketplace/import/export primitives.

## Wave 18 — Browser/computer + integration expansion
Sandboxed browser/computer execution, MCP/tool server, public API/webhooks, plugin SDK, connector catalog.

## Wave 19 — Desktop/mobile
Desktop OS integrations, local files/tools where authorized, mobile approvals/monitoring/comms/tasks, push notifications.

## Wave 20 — Productization / enterprise readiness
Multi-user hardening, SSO/custom roles, billing/entitlements, admin/trust console, retention/export/delete, compliance controls, scale/load, disaster recovery.

### Final Gauntlet
Security, privacy, tenant isolation, prompt injection, sandbox escape boundaries, connector scopes, autonomous-action controls, financial/data correctness, accessibility, performance, recovery, provider outages, model fallback, adversarial software-build tests, end-to-end founder workflows.

## Parallelization
Traycer/XIO planner may overlap waves after interfaces are approved. FORGE foundations should be prioritized because XIO should progressively dogfood its own build system.
